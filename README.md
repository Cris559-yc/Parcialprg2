Este proyecto contiene ejemplos prácticos del uso de la librería Faker en Python.
La finalidad es demostrar cómo generar datos sintéticos realistas (nombres, correos, direcciones, usuarios web y tarjetas de crédito ficticias).
Requerimientos:
Python 3.8 o superior
Visual Studio Code (o cualquier editor compatible con Python)
Librería Faker
- primero instalar la libreria faker desde la terminal con el comando: pip install faker
- Ahora solamente clonar el repositorio.
